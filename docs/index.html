Markdown reader for macOS and Windows

Type sized from where you sit.

A point size means nothing on its own. What your eye sees is the angle a letter covers, and that depends on how far the screen is and how many pixels it packs into an inch. Muo measures both and solves for the size.

0.32° · 72ch
18.0 pt

The largest effect on reading comfort is how many characters sit on a line. Too few and the eye finishes before it has parsed the sentence. Too many and the return sweep to the next line loses its place, so you re-read the same line without noticing. Drag the slider and watch the gauge.

The band between 0.26° and 0.38° is where reading stays comfortable. The gauge shows where you land.

The column is capped in characters, not pixels.

A pixel cap looks stable. It quietly changes the character count whenever the type size changes, so it is right on one screen and wrong on another. Muo holds the measure at 72 characters and lets the physical size of the page follow the hardware.

A reader is a machine for one job, getting words from a screen into a head with as little friction as possible. Everything else exists to keep that job from being interrupted.

Three panes, one window.

Files on the left, the page in the middle, the document's own headings on the right. Every divider drags. Every pane folds away and comes back where you left it.

What else is in it.

Find, with marks on the page

Every match is highlighted where it sits, headings included. Enter walks them. In a PDF, Find reads the page text and turns to the page the match is on.

Code you can tidy

Go and JSON go through the standard library. Other languages get spacing and indentation that never reaches inside a string or a comment. Format tells you when there is nothing to change.

It remembers

Your place in each document, the width of each pane, which panes you folded, and the files you had open. Close the window and it comes back as you left it.

One dependency

The whole app is Go, drawn on the GPU by MyGo. No webview, no JavaScript runtime, no frontend build. It opens in about a second.

Build it yourself.

Muo is Go and one module. You need Go 1.24 or newer.

git clone https://github.com/yaffalhakim1/muo
cd muo
go build -o muo .
./muo sample.md

On Windows the binary is muo.exe. For live reload while you edit, go run github.com/egoist/mygo/cmd/mygo@v0.6.3 dev . rebuilds and restarts the window on save.
