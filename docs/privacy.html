Muo

Privacy

Muo reads files from your disk and writes two small JSON files to your user data folder. It sends nothing anywhere unless you ask it to check for updates.

What is stored, and where

Two files, in your platform's user data directory:

  • reading-state.json holds where you stopped in each document, keyed by file path.
  • layout.json holds the width of each pane and whether you had it open.

On Windows that is %APPDATA%\Muo. On macOS it is ~/Library/Application Support/Muo. Uninstalling the app does not delete them, on purpose, so your place in a document survives a reinstall. Delete the folder yourself if you would rather it did not.

What is never collected

No account. No analytics. No crash reports. No usage data. No telemetry of any kind. The app has no network code beyond the update check.

Network access

One request, and only when you choose to check for an update: the app fetches a manifest from this project's GitHub releases and compares versions. If a newer one exists, it downloads the archive for your platform and verifies its signature before running anything.

Opening a link in a document hands the URL to your browser. That is your browser's traffic, not the app's.

Your documents

Muo reads the file you open and keeps its contents in memory while the window is open. Nothing is uploaded, copied elsewhere, or indexed in a shared store.

This site

These pages are static files served by GitHub Pages. They set no cookies and load no analytics. Two web fonts come from Google Fonts, which means Google sees the request for them. Nothing else leaves your browser.
