# Tools

Scripts used while working on the app. None of them are needed to build or run Muo.

| File | What it does |
| --- | --- |
| `appshot.ps1` | Captures the Muo window, for looking at the live app |
| `shot.ps1` | Launches the app on `sample.md` and captures the screen |
| `check-page.js` | Structural checks on `docs/index.html`: duplicate ids, dead element references, missing images, motion violations |
| `check-gauge.js` | The landing page's gauge arithmetic: the marker stays inside its track and the band lands where the comfortable range says |
